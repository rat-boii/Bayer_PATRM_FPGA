# Memory-access model, step 1.4

**Our interpretation** of the paper's scheme (blocks = runs of output pixels sharing source row x0, capped at Lmax; ping-pong prefetch). **All speeds are ESTIMATES** from cycles = max(pixels / pixels-per-clock, read beats + 2 x read bursts) at 100 MHz; port ceiling 64 bit x 100 MHz = 800 MB/s (theoretical). Full data: `memmodel_step1_4.csv`. P0 = fetch both rows every block; P1 = reuse rows the previous block already holds. amp = bytes read / (W x H).
