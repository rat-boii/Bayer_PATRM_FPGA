## Decided 2026-11-06 (step 0.1 inputs)
- Verilog-2001, xsim, Vivado/Vitis 2026.1, Windows native (WSL has no Vivado). Python scripts run on Windows.
- XSCT does not exist in 2026.1: board scripts use XSDB (Tcl, or Python XSDB); Vitis projects via the Vitis Python API (`vitis -s`).
- Claude Code runs in the repo; repo root CLAUDE.md carries the conventions (Claude Code cannot see this project).
- D1 edge rule: valid iff 0 <= x <= H-1 and 0 <= y <= W-1 (Q15.16 compare), else 0; next-row/col neighbour clamped (weight 0 there). Bayer: plane size.
- D2 t_p: from quantised Q15.16 integers, then arithmetic >>1.
- D3 sizes: gray W%8==0; Bayer W%16==0 and H even; others rejected, no padding. Tests: 480x272, 640x480, 800x480, 1920x1080, 2448x2048 (Bayer large), gray also 2448x2095 (paper size).
- D4 overflow: plain 32-bit wrap in RTL; software rejects transforms whose 4 output corners map beyond +/-16384 px.
- D5 coefficient quantisation: floor(v*65536 + 0.5). D6 Option B lane offset = register difference T_p - T_R (not (A-I)o/2 recomputed; D2 rounding can differ by 1 LSB). D7 all sizes written W x H. D8 PL clock 100 MHz for every build; 150 MHz only as an Fmax experiment in 7.3. D9 resource/timing/speed numbers from builds without the ILA (ILA = debug build option).
- D10 interpolator = option A2 (2026-11-07): xf,yf = low 16 bits; w2=((65536-xf)*yf)>>16, w3=(xf*(65536-yf))>>16, w4=(xf*yf)>>16, w1=65536-(w2+w3+w4); D=(w1*r1+w2*r2+w3*r3+w4*r4)>>16. 7 multipliers (3 weight + 4 pixel), each fits one DSP48E1; weights sum exactly to 1 (flat stays flat). Measured on a 15-deg rotation: A2 differs from exact maths on 0.02% of pixels (max 1 level) vs 71% for the paper-style 4-weight truncation (which turns 255 into 254). Replaces the '8 multipliers' convention. Worked example: X=209715, Y=288360, xf=13107, yf=26216, w=(31458,20972,7863,5243), D=120.
- Block length does not affect results (integer stepping == multiply exactly, mod 2^32); it is a memory/prefetch parameter decided in 1.4/2.2, not 1.1.
- b is the inverse map; PC helper builds it from forward params in float, quantises round-to-nearest; ARM never does float transform maths. Integer part = >>16 (floor).

## Decided 2026-11-10 (steps 2.1, 2.2)
- D11 max image size 4096 x 4096; WIDTH/HEIGHT 13-bit registers; above 4096 or breaking D3 for the mode -> STATUS.error, no start.
- D12 ARM computes T_R/T_Gr/T_Gb/T_B with the D2 integer formula (model/bayer.py plane_shifts) and writes the registers; hardware never recomputes; Option B lane offsets = T_p - T_R (D6).
- D13 BLOCK_LEN register (1..BLOCK_LEN_MAX); BLOCK_LEN_MAX is a synthesis parameter chosen in 2.2 from the 1.4 numbers; out of range -> STATUS.error.
- D14 fetch policy P1: skip a row fetch when the previous block already holds that row with a covering column range.
- D15 BLOCK_LEN_MAX = 64 (synthesis parameter; BUILD_ID.BLOCK_LEN_MAX = 64; driver default BLOCK_LEN = 64).
- D16 block ends at the first of: (a) source top row x0 changes, (b) BLOCK_LEN pixels, (c) a needed row's column span would exceed SPAN_MAX = 512 bytes; buffers never overflow, every D4-valid transform supported (speed varies). Closes "largest rotation/scale".
- D17 (2026-11-15) no SystemVerilog unless completely necessary: RTL and testbenches are Verilog-2001 (.v only; xvlog and read_verilog without -sv; Verilog-2005 system functions accepted in plain Verilog mode such as $clog2 are fine). Vendor IP that is SystemVerilog inside (Zynq-7000 VIP, ILA) is allowed; our testbench around it stays Verilog. No AXI VIP: our own Verilog memory model. If SystemVerilog seems needed: stop and ask. Enforced by scripts/check_no_sv.py (run by sim.py).

## Steps (Where -> Produce -> Verify)
Phase 0 Setup
- 0.1 Toolchain + repo: same tool versions; counter sims.
- 0.2a PS-only build on laptop (no board): ZedBoard preset (NOT ZC702); apply ZedBoard preset, then D18 DDR part override; XSA + bitstream + hello ELF, load_run scripts with --dry-run. 0.2b (board arrives): run hello over USB-UART via JTAG (XSDB load_run.tcl), twice.
- 0.3 (needs board) JTAG DDR round trip: put_image.tcl / get_image.tcl; 1 MB and 5 MB cmp-identical; record s/MB. A random mismatch in this round trip is first checked against the PS DDR part setting (D18). Proposed buffers: src 0x1000_0000, dst 0x1800_0000.

Phase 1 Python model (laptop)
- 1.1 model/patrm.py: Q15.16, inverse coeffs, block start by multiply-add then add-only stepping (same 32-bit wrap as RTL), bilinear, truncate to 8 bits, out-of-range 0, stream dumps. Verify: worked example (3,2)->(3.2,4.4)->120; identity; integer shift; column mirror (b22=-1, b23=W-1); 5/15/37 deg vs independent float warp within small tolerance.
- 1.2 gen_images.py, transforms.json, gen_vectors.py (.hex for TBs). Sizes: 64x64, 128x96 (sim); 480x272, 640x480, 800x480, 1920x1080, 2448x2048, gray 2448x2095 (board). All W x H.
- 1.3 model/bayer.py: split, t_p, warp per plane, re-interleave. Verify: t_p vs full-res mapping on random points; t_B = (39321, 45875) Q15.16 ints from quantised b = (52429, -39322, 131072, 39322, 52429, 65536); identity; even shift; PSNR sanity only.
- 1.4 model/memmodel.py: per-block source span (Δv=1/|b12|), AXI burst list (<=16x8 B, no 4 KB crossing), ping-pong depth, predicted bytes for gray/A/B (A ~2x B reads).

Phase 2 Spec (laptop)
- 2.1 spec/regs.json -> regs.h, regs.vh, regs.py. Proposed map: 0x00 CTRL (start, mode 0/1/2, int en), 0x04 STATUS (busy, done W1C, error), 0x08/0x0C SRC/DST_ADDR, 0x10/0x14 WIDTH/HEIGHT, 0x18-0x2C B11..B23, 0x30-0x4C T_R/T_GR/T_GB/T_B (x,y), 0x50 CYCLES, 0x54/0x58 BYTES_RD/WR, 0x5C/0x60 RD/WR_STALL, 0x64 BUILD_ID. HP0 read, HP1 write, 64-bit; done interrupt -> IRQ_F2P[0].
- 2.2 spec/interface.md: ports, valid/ready, widths, latencies, truncation points; LaTeX block diagram.

Phase 3 Grayscale RTL (sim + OOC synth each)
- 3.1 axil_regs + interrupt. 3.2 coord_gen (vs coordinate dump). 3.3 bilinear_interp (D10/A2, 7 multipliers; 100k vectors, latency 4, II 1).
- 3.4 tb/axi_mem.v + axi_rd_master (16-beat, 4 KB split, >=2 outstanding). 3.5 out_fifo + axi_wr_master (WSTRB).
- 3.6a block_planner (spec section 3; block list == step 2.2 block-list vectors, D14-D16). 3.6b prefetch_ctrl + ping-pong BRAM + pixel_fetch (burst list = memmodel). 3.7 ctrl_fsm + patrm_top full-frame bit-exact at 64x64/128x96/256x192, all transforms including rot90/rot180. 3.8 OOC impl, WNS>=0 at 100 MHz, utilization saved.

Phase 4 Board grayscale (= Stage 1 done)

Phase 5 Bayer Option A
