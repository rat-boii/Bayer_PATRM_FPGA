# AGENTS.md

This file is for every coding agent working in this repo (Codex, Claude Code or another tool).

1. **The rules are in `CLAUDE.md`. Read all of it before any task and follow it exactly.** It is the single rule
   file for every agent and every teammate; this file deliberately does not copy it, so the two cannot drift apart.
   The name says "CLAUDE" only for historical reasons.
2. On a laptop you have not used before, or after a fresh clone, run `python scripts/check_setup.py` first and follow
   its fixes before any step. Board and Vitis setup is per laptop; see README "New laptop setup".
3. The plan, every decision and the progress log are in `docs/implementation-plan.md`. Work one step at a time.
4. **Ethernet link and GUI (plan Phase 10):** start with `docs/handover-ethernet-gui.md`. It says what exists, what
   to build, which files that work may change, and which it must not touch.
